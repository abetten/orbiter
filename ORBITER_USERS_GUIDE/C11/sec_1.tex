The command

\sourcecode{nonlinear_code_long_n7_k4}

creates the code $\cC$ in $H(7,2)$ whose codewords are 
$$
{\bf w}_1 = 1100000, \; 
{\bf w}_2 = 0111000, \; 
{\bf w}_3  = 1101101, \; 
{\bf w}_4  = 0011011.
$$
The command computes the distance matrix $(d_{ij})$ where 
$d_{ij} = d({\bf w}_i,{\bf w}_j)$ 
the distance between codeword ${\bf w}_i$ and codeword ${\bf w}_j$.
Moreover, the command computes the external distances for all elements not in the code. 
Here, for $\by \not\in \cC$ we have 
$$
d(\by,\cC) = \min \{ d(\by,{\bf w}) \mid {\bf w} \in \cC \}
$$
the external distance of $\by$ w.r.t. $\cC$.
Both, the distance matrix and the external distance vector are written to csv files.

\sourcecode{nonlinear_code_n7_d4}

creates the code $\cC$ in $H(7,2)$ whose codewords are 
$$
0,15,51,60,85,90,102,105.
$$
Again, the distance matrix and the external distances are computed and written to file.

\sourcecode{nonlinear_code_n7_d4_classify}
