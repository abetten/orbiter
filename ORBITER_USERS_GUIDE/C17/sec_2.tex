
Suppose we want to check whether the 2 sets of points 
$$
\{0,1,2,3\}, \; \{1,3,4,6\}
$$
are equivalent in $\PG(2,2)$. 
The following command creates a combinatorial object for each of the two sets 
and invokes the nauty-based classification-by-canonical-form algorithm. 

\sourcecode{quadrangles_PG_2_2}


It turns out that the two sets are equivalent. 
Both are quadrangles. 
The stabilizer is computed to be of order 24. 
Generators for the group are given.

Let us compute the group of the Barth sextic. 
In Section~\ref{sec:algebraic:varieties:activities}, 
we computed the set of 65 singular points. 
Next, we will compute the stabilizer of these points. 
To begin with, 
we define a makefile variable with these points in Orbiter codes:

\sourcecodevariable{BARTH_SEXTIC_MOD_11_SINGULAR_POINTS}

The next command performs the 
classification-by-canonical-form algorithm. 
At first, we create a combinatorial object from the set of singular points.
After creating the finite field $\bbF_{11}$ and the projective geometry $\PG(3,11)$, 
a combinatorial object activity of type \verb'canonical_form_PG' 
is called to compute the canonical form and the automorphism group of the object. 
A second combinatorial object activity of type \verb'report' 
is called to produce a latex report.
The report includes the tactical decompositions 
of the decorated incidence matrix called the TDO and TDA. 
%by ordering and by automorphisms (TDO and TDA):

\sourcecode{Barth_mod_11_singular_pts_c}


It turns out that the set is stabilized by a group of order 120. 
Generators mod 11 are given.

The following sequence of commands generates 
and classifies all quartic curves with 28 bitangents 
in the plane over the field $\bbF_{13}$.
As first, we need a makefile variable for the number 
of isomorphism types of cubic surfaces with 27 lines over this field:

\sourcecodevariable{NB_CUBIC_SURFACES_Q13}

Next, we create candidates for the quartic curves 
by projecting from a point on the surface but not on any line. 
There can be multiple such points. 
For each orbit under the automorphism group, 
one point is chosen as a representative of this orbit. 
Using the procedure described in~\cite{Hirschfeld10}, 
the associated quartic curve is created.
We then concatenate the output files.
Finally, we perform a classification of the curves.
We employ the nauty-based 
classification-by-canonical-form algorithm.
The following command sequence 
does the job:


\sourcecode{quartic_curves_q13_classify_nauty}

Over the given field $q=13$, we find exactly two isomorphism types. 
The Orbiter knowledge base of combinatorial objects is built by assembling output files 
from classifications like this one in the form of C++ source code. 
The previous command creates a C++ source file containing these curves for 
importing into Orbiter. 
The command also creates a csv file containing the classification of all flag orbits.
The output of the command is shown below, showing the canonical equation of each curve, 
the automorphism group by means of generators and group order, 
and the number of rational points of the curve over the given field.

\orbiteroutput{GRAPHICS/LATEX/quartics_q13_orbits}

In Section~\ref{sec:algebraic:varieties:activities}, 
we have created a Veronese variety over the field $\bbF_7$. 
The following command computes the stabilizer of this variety. 

\sourcecode{Veronese_1_3_q7_c}

The points are printed with their homogeneous coordinates:

\orbiteroutput{GRAPHICS/LATEX/Veronese_1_3_q7_c_points}

The automorphism group is determined to have order 336. 
Generators are computed:

\orbiteroutput{GRAPHICS/LATEX/Veronese_1_3_q7_c_auto}

A coding of the generators is printed at the very end. 
This coding can be used later to recreate the group.
Finally, a tactical decomposition is produced. 
This is the extended incidence matrix of $\PG(3,7).$ 
One artificial point and one artificial line 
are introduced to encode the variety as a 
combinatorial object. 
The TDO is obtained by refining the partition.

\orbiteroutput{GRAPHICS/LATEX/Veronese_1_3_q7_c_TDO}
