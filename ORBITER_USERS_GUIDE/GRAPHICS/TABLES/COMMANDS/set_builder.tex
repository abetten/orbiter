	\verb'-set_builder' & set & Use a set as input to a construction.\\
	\hline
	\verb'-clone_with_affine_function' & a b & Apply the affine function $ax+b$ to the elements $x$ of a set specified using \verb'-set_builder'. \\
	\hline

	\hline
	\verb'-here' & elements & Create the set from the given list of elements. The elements of the list are comma separated. \\

	\verb'-file' & fname & Create a set from the elements listed in the given file. \\
