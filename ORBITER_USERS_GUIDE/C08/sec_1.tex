
Orbiter provides three different orbit algorithms: 
\begin{enumerate}[(i)]
\item
Schreier trees, 
\item
poset classification, and 
\item
orderly generation using canonical forms. 
\end{enumerate}
The ``orbit'' Orbiter object provides a front end to all three orbit algorithms. 
For background on Schreier trees, see~\cite{Butler91,Holt05,Seress03}.
Poset based algorithms will be discussed in Section~\ref{sec:posetclassification}.
Orderly generation using canonical forms is discussed in 
Section~\ref{sec:canonical:form:objects:PG}.

In the next example, we 
compute the orbits of 
the linear group $\PGL(3,2)$ on plane cubics: 

\sourcecode{poly_orbits_d3_n2_q2_compute}

The command produces a latex report about the orbits 
and a csv-file containing additional data. 
The csv-file is shown below, 
as seen through a spreadsheet program.


\orbiteroutput{GRAPHICS/WRAPPERS/poly_orbits_d3_n2_q2_table}


The columns are 
\begin{trivlist}
\item
Row -- the row in the table.
\item
OrbIdx -- The orbit index (same as Row).
\item
Go -- The order of the stabilizer of the variety in the group that was used to compute the orbits.
\item
EqnCode -- To Orbiter rank of the equation. 
\item
EqnVec -- The coefficients of the equation in vector form.
\item
EqnAf -- The equation of the variety written in algebraic form. 
\item
NbPts -- The number of $\bbF_q$-rational points of the variety.
\item
Pts -- The set of $\bbF_q$-rational points of the variety in Orbiter codes.
\end{trivlist}


\bigskip


In the next example, we 
compute the orbits of 
the linear group $\PGL(4,2)$ 
on homogeneous polynomials of degree 3 in 4 variables: 

\sourcecode{poly_orbits_d3_n3_q2.csv}

This command computes the orbits of 
all cubic forms in 4 variables over the field $\bbF_2$, 
confirming the work of Dickson~\cite{Dickson15} 
and an enumerative result of Cooley~\cite{Cooley14}.
