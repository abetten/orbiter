Orbiter supports two orderings of the monomials.
\begin{enumerate}
\item
The lexicographic ordering orders the monomials lexicographically.
\item
In the partition ordering, 
the monomials are first ordered according to the partition 
arising from the exponent vector. 
For monomials with the same partition, 
the lexicographic ordering is used as a tie breaker. 
\end{enumerate}
By default, the partition ordering is used.

The variables are written as \verb'y0', \verb'y1', \verb'y2', respectively.

The following command creates the permutation polynomial associated with the map 
$$
\sigma : \bbF_5 \rightarrow \bbF_5,  
\left[
\begin{array}{ccccc}
0 & 1 & 2 & 3 & 4 \\
3 & 0 & 4 & 1 & 2 \\ 
\end{array}
\right]
$$
\sourcecode{permutation_polynomial_F5}
The code utilizes the basis functions
$$
\delta_{x,i} = 1-(x-i)^{q-1}
$$ 
of $\bbF_5,$
which are one if $x=i$ and zero otherwise.
Because Orbiter offers homogeneous polynomials only, 
a polynomial ring in two-variables is utilized. 
The polynomials are homogeneous of degree $q-1 = 4.$
We can write 
\begin{eqnarray*}
\sigma &=& \sum_{i=0}^4 \sigma(i)\delta_{x,i} \\
&=& 
\sigma(0)\delta_{x,0} + 
\sigma(1)\delta_{x,1} + 
\sigma(2)\delta_{x,2} + 
\sigma(3)\delta_{x,3} + 
\sigma(4)\delta_{x,4} \\
&=& 
3\delta_{x,0} + 
0\delta_{x,1} + 
4\delta_{x,2} + 
1\delta_{x,3} + 
2\delta_{x,4}, \\
&=& 
3(1-x^4) + 
4(1-(x-2)^4) + 
(1-(x-3)^4) + 
2(1-(x-4)^4), \\
\end{eqnarray*}
because 
$$
\sigma(0) = 3,
\sigma(1) = 0,
\sigma(2) = 4,
\sigma(3) = 1,
\sigma(4) = 2.
$$
After expansion, the permutation polynomial associated with $\sigma$ 
turns out to be 
$$
%Yx = 
\begin{array}{*{1}c}
3 + x^{3} + (3 x^{2}) + (3 x).\\
\end{array}
$$

The next example is about a conic. We want to find the set of rational points of the conic 
$$
X_0^2-X_1*X_2
$$ 
over $\bbF_{13}.$ After that we want to find the ideal in the polynomial ring which vanishes on this point set. 
At first, we compute the $\bbF_{13}$-rational points of the variety using the following command. The command utilizes a 
veriety object, which will be discussed in Section~\ref{sec:algebraic:varieties}.

\sourcecode{conic_variety}


\bigskip

The set of points in Orbiter numbers is 
$$
1, 2, 3, 39, 57, 62, 68, 77, 134, 141, 150, 151, 175, 178.
$$
The following command creates the ideal of quadratic polynomials vanishing on this set:


\sourcecode{ideal_of_conic}

The ideal is generated by  
$$
X_0^2 + 12*X_1*X_2.
$$
Here, we recall that $-1$ is represented as $12$ in $\bbF_{13}.$

\sourcecodevariable{QC_Q27_FO159_COEFFS}

\sourcecodevariable{QC_Q27_FO388_COEFFS}

Suppose further that we have a transformation as in the following 
makefile variable:

\sourcecodevariable{QC_Q27_FO388_TRANS}

The following command applies the transformation to the second equation:


\sourcecode{quartic_curve_q27_fo338_apply_transformation}

The output of the command shows the image equation as
$$
( 1, 12, 13, 4, 23, 3, 26, 15, 1, 0, 23, 24, 0, 0, 3 )
$$
which is the first equation up to a scalar multiple.
