
The following typographic conventions are used in this document:

\bigskip

Makefile excerpts are in color coded boxes. 
Line numbers have been added for clarity.
A tabulator symbol is indicated 
as a little triangle pointing to the right.
Tables are color coded: 

\bigskip

A blue box indicates a piece of data that is given 
as a makefile variable, like so:

\sourcecodevariable{HAMMING_CODE_GENERATOR}

\bigskip


A red box indicates 
a table of Orbiter commands. 



\sourcecode{matrix_example2}



A green box signifies some other kind of table. 


\bigskip



Makefile variables are purely based on text. 
They can be utilized using the dollar-parenthesis syntax.
For instance, the makefile variable 
$$
\verb'HAMMING_CODE_GENERATOR'
$$
has been defined above. 
To use a makefile variable, 
the dollar-parenthesis syntax is used. For instance, 
$$
\verb'$(HAMMING_CODE_GENERATOR)'
$$
represents the contents of the variable.


\bigskip

A piece of output created by Orbiter is put in a black frame, like so:

\orbiteroutput{GRAPHICS/THE_MAKEFILE/EXTRACTS/test_orbiter_session_log}

\bigskip
