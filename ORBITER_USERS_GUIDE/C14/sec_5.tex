It is possible to create flag transitive desgns from 
a group $G$ and two conjugacy classes of subgroups, represented by groups $P$ and $Q,$ both subgroups of $G$.
The groups in the class of $P$ serve as the point stabilizers. The groups in the class of $Q$ serve as the block stabilizers. 
The following sequence of commands recreates the design of~\cite{Praeger2007}.
 
Using a makefile variable, we define 8 elements in $\AGGL(1,81)$ as follows:

\sourcecodevariable{PRAEGER_DESIGN_45_12_3_GENS}

Let $G$ be the group of order 3240 generated by these elements. 
We create a flag-transitive design from the group generated by these elements. The following command is used:

\sourcecode{Praeger_design_45_12_3}

The command creates the intersection matrix between the groups in $\tilde{L}$ and in $\tilde{R}$ where 
$\tilde{P}$ denotes the conjugacy class of subgroups of $P$ inside $G$.


The next command creates the relation defined 
by the pairs of groups whose intersection of size 6. 

\sourcecode{Praeger_design_change_values}


The following command creates the design from the relation created before 
and performs some basic activities for it:

\sourcecode{Praeger_45_12_3_design}

The following command creates the full stabilizer of the design:

\sourcecode{Praeger_45_12_3_design_c}


The full stabilizer of the design has order 19440.
The command also produces a drawing of the action of the 
group on the flags and anti-flags, shown below:
