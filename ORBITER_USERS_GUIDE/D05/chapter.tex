
\section{The Makefile}
\label{sec:makefile}


The examples in this guide are taken from a makefile. 
The complete makefile is distributed with Orbiter 
in the directory 
$$
\verb'examples/users_guide'
$$
The makefile can be used as a sort of index of all Orbiter commands. 
In most cases, it is possible to find an example 
for a given Orbiter command by simply searching for this particular command inside the makefile.

\bigskip

We advise against running any commands in the orbiter directory tree. 
Running the makefile within the orbiter tree will create files that make updating orbiter through git more difficult.
Therefore, we recommend to copy the makefile to some location {\em outside} 
the orbiter tree, see Section~\ref{sec:work:directory}.
