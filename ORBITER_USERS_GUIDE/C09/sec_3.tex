As described in the previous section, 
it is possible to create a cubic surface at random. 
The following command creates a random surface over the field $\bbF_{11}$. 
Random means that each isomorphism type 
of surface appears with equal probability. 
Since surfaces may have different stabilizer orders, 
this is different from 
the equidistribution over all surfaces 
with 27 lines for a given finite field.

\sourcecode{surface_11_random_report}

\orbiteroutput{GRAPHICS/LATEX/surface_random_q11_report}

It is possible to recognize a cubic surface as a member of the $\cF_{a,b,c,d}$ family.
We can determine elements $a,b,c,d$ in $\bbF_q$ such that 
$\cF_{a,b,c,d}$ is isomorphic to the given smooth surface. 
This relies on the classification of non-conical $6$-arcs in 
the associated projective plane $\PG(2,q)$. 
The following command 
shows how to classify the non-conical $6$-arcs in the plane 
and how to recognize a surface. 
In the example, we create the surface 
over $\bbF_8$ with catalogue number 0:

 
\sourcecode{surface_8_0_recognize_abcd}
